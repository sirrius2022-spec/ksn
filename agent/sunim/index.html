STEP 1

음성 엔진 · 원고

키 발급: Google Cloud 콘솔 → Text-to-Speech API 사용 설정 → 사용자 인증 정보 → API 키. 월 무료 한도(신경망 100만 자) 내 과금 없음.
녹음 방식: 변환 시작 → 공유 창에서 「전체 화면」 + 「시스템 오디오 공유」 체크 → 재생되는 소리를 그대로 녹음. Windows Chrome·Edge 권장(Edge는 고품질 ‘Natural’ 음성 제공). 녹음 중 다른 소리 재생 금지. 법당 잔향은 효과음에만 적용.
직접 녹음했거나 다른 TTS로 만든 음성에 효과를 입힘. ‘문장 사이 목탁’은 음성의 쉼 구간을 자동 감지해 배치.
