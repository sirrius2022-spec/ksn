GitHub 연결 설정

최초 1회만 입력하면 이 브라우저에 저장됩니다. (다른 기기에서는 다시 입력)
저장소 루트가 아니라 폴더 안에 넣었다면 그 경로를 정확히 적어야 합니다. (예: 이 페이지 주소가 .../agent/text/admin.html 이라면 agent/text/content.json)
토큰은 어디서 만드나요? GitHub → 우측 상단 프로필 → Settings → Developer settings → Fine-grained tokens → Generate new token.
Repository access는 이 저장소 하나만 선택하고, Permissions에서 "Contents: Read and write"만 켜주세요.
