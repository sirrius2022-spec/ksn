🚀 마법의 4단계 실습 과정

각 단계별로 강사가 한 방식을 보고, 내 주제에 맞춰 내용을 바꿔보세요.

1

✨ 제미나이(Gemini)에 요청하기

"코드를 대신 짜주는 AI 비서에게 내 주제를 설명합니다."

"건설안전 강의용 홈페이지를 HTML 하나로 만들어줘. 강사 소개, 룰렛 게임 메뉴, 계산기 메뉴를 넣어줘. 파란색 톤으로 깔끔하게 해줘."
"팀 업무 매뉴얼 홈페이지를 HTML 하나로 만들어줘. 팀 소개, 회의록 양식, 휴가 신청법 메뉴를 넣어줘. 초록색 톤으로 깔끔하게 해줘."
2

🐙 깃허브(GitHub)에 코드 저장하기

"제미나이가 짜준 코드를 전 세계 무료 저장소에 올립니다."

  • GitHub 회원가입 후 New 버튼 클릭
  • 창고 이름(Repository name) 짓기
    (강사: ksn-edu / 여러분: my-camping, team-manual 등)
  • Add file -> Create new file 클릭
  • 파일 이름은 무조건 index.html 로 적고 내용 붙여넣기
  • 초록색 Commit changes 버튼 누르면 저장 완료!
3

▲ 버셀(Vercel)로 세상에 공개하기

"저장된 코드를 실제 인터넷 주소(URL)로 연결하는 마법!"

1. Vercel 가입 시 Continue with GitHub 선택 (이게 핵심!)

2. 화면 중앙의 Add New -> Project 클릭

3. 방금 만든 GitHub 창고 옆의 Import 클릭

4. Deploy 버튼을 누르고 10초만 기다리면 완성!

🎉 축하합니다! 이제 스마트폰으로 접속 가능한 나만의 주소가 생겼습니다.
4

📝 패들렛(Padlet)으로 방명록 달기

"만들어진 홈페이지에 방문자와 소통할 게시판을 붙입니다."

게시판 코딩은 어렵습니다. 무료 게시판 서비스인 Padlet 링크를 가져다 붙이는 게 왕초보의 지름길입니다.
